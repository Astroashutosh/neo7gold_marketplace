# WebGi Jewelry — Next.js

Converted from the original Parcel + TypeScript WebGi jewelry demo to Next.js.

## Node

Designed to run with Node.js 24.x. The old Parcel 1/deasync dependency has been removed.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

Production:

```bash
npm run build
npm start
```

The original WebGi `.glb`, image and audio assets are kept under `public/assets`.
